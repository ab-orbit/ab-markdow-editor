# Bundled Excalidraw libraries

These seven collections are shipped with Scriba for offline use. Their original bytes and SHA-256 digests are recorded in [catalog.json](catalog.json). Collections use the [MIT license](LICENSE) published by the [Excalidraw libraries project](https://github.com/excalidraw/excalidraw-libraries).

| Collection | Author | Items |
| --- | --- | --- |
| [Software Architecture](https://libraries.excalidraw.com/libraries/youritjang/software-architecture.excalidrawlib) | youritjang | 7 |
| [System Design](https://libraries.excalidraw.com/libraries/rohanp/system-design.excalidrawlib) | rohanp | 24 |
| [Data Viz](https://libraries.excalidraw.com/libraries/dbssticky/data-viz.excalidrawlib) | dbssticky | 32 |
| [Awesome Icons](https://libraries.excalidraw.com/libraries/ferminrp/awesome-icons.excalidrawlib) | ferminrp | 24 |
| [Algorithms and Data Structures](https://libraries.excalidraw.com/libraries/intradeus/algorithms-and-data-structures-arrays-matrices-trees.excalidrawlib) | intradeus | 22 |
| [Icons](https://libraries.excalidraw.com/libraries/xxxdeveloper/icons.excalidrawlib) | xxxdeveloper | 65 |
| [Post-it](https://libraries.excalidraw.com/libraries/ferminrp/post-it.excalidrawlib) | ferminrp | 13 |

Scriba adds the 187 symbols once to each origin's private library. Personal symbols remain intact. Later edits, removal or clearing are respected; opening another drawing does not reinstall removed symbols. Author attribution and full license travel with the application assets.
