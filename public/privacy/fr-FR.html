Politique de confidentialité de Scriba

Mise à jour le 22 octobre 2026. Scriba — Vos idées en Markdown, développé par Aeon Bridge Co.

Vos notes

Vous pouvez utiliser l’éditeur sans créer de compte. Les notes, images, dessins, préférences et brouillons restent sur votre appareil. Dans la version web, ils sont conservés dans le stockage privé du navigateur. Dans l’application pour iPhone et iPad, ils sont conservés dans le stockage privé de l’application. Ils ne sont pas publiés automatiquement.

Lorsque vous choisissez un dossier, Scriba peut lire les fichiers Markdown existants et enregistrer les notes et les images dans le sous-dossier scriba. L’application iOS conserve l’autorisation du dossier accordée via Fichiers. Vous pouvez déconnecter le dossier dans les réglages. L’exportation d’un fichier ne partage que le contenu choisi avec la destination que vous sélectionnez.

Connexion facultative à GitHub

Lorsque vous connectez GitHub, le service de synchronisation de Scriba reçoit votre identifiant de compte et l’autorisation nécessaire pour accéder aux dépôts autorisés. La session et les identifiants sont chiffrés sur le serveur. Dans l’application iOS, l’identifiant opaque de session est conservé dans le trousseau ; les identifiants OAuth ne sont pas renvoyés à l’éditeur. Si vous choisissez de fournir un jeton d’accès personnel, il est envoyé au service de connexion et n’est pas conservé dans le stockage web.

Lors de la synchronisation, les fichiers Markdown et les images transitent par le service Scriba pour être lus depuis votre dépôt GitHub ou y être enregistrés. Le service ne conserve pas de bibliothèque de documents sur le serveur. GitHub conserve les fichiers et l’historique des commits conformément à vos autorisations et à la politique de confidentialité de GitHub. Les fichiers envoyés dans des dépôts publics sont publics.

La déconnexion de GitHub supprime la session du service ; elle ne supprime pas votre dépôt. Vous pouvez aussi révoquer les autorisations dans les paramètres de votre compte GitHub. Les sessions inactives expirent après sept jours. La suppression d’une note sur votre appareil ne supprime pas les anciens commits GitHub.

Infrastructure

Le site et le service de synchronisation utilisent HTTPS et Cloudflare. Ces services traitent des données techniques de connexion, comme l’adresse IP, l’heure et le chemin demandé, afin de fournir et de protéger le service. La version web peut utiliser les mesures techniques fournies par Cloudflare. Le paquet iOS natif ne contient aucun SDK de publicité, de suivi ou d’analyse d’utilisation.

Scriba ne demande pas l’accès aux contacts, à la localisation ou au microphone et ne lit pas votre photothèque en arrière-plan. Vous choisissez les images et les fichiers à l’aide des sélecteurs du système ; l’appareil photo n’est utilisé que si vous choisissez de prendre une photo à insérer dans une note. Nous ne vendons pas vos notes, n’utilisons pas votre contenu à des fins publicitaires et n’envoyons pas les dessins aux serveurs d’Excalidraw ou de Mermaid pour les afficher.

Contrôle et suppression

Exportez vos notes et vos images avant d’effacer les données du site ou de supprimer l’application. Ces actions suppriment les copies privées de l’appareil. Les fichiers enregistrés dans Fichiers, GitHub ou une autre destination y restent. Les préférences, les brouillons de dessins et les bibliothèques privées de symboles restent sur l’appareil jusqu’à l’effacement des données de l’application.
