Datenschutzerklärung von Scriba

Aktualisiert am 22. Oktober 2026. Scriba — Ihre Ideen in Markdown, entwickelt von Aeon Bridge Co.

Ihre Notizen

Sie können den Editor nutzen, ohne ein Konto zu erstellen. Notizen, Bilder, Zeichnungen, Einstellungen und Entwürfe bleiben auf Ihrem Gerät. In der Webversion werden sie im privaten Speicher des Browsers abgelegt. In der App für iPhone und iPad werden sie im privaten Speicher der App abgelegt. Sie werden nicht automatisch veröffentlicht.

Wenn Sie einen Ordner auswählen, kann Scriba vorhandene Markdown-Dateien lesen und Notizen und Bilder im Unterordner scriba speichern. Die iOS-App behält die über die App „Dateien“ erteilte Ordnerberechtigung. Sie können den Ordner in den Einstellungen trennen. Beim Exportieren einer Datei werden nur die von Ihnen ausgewählten Inhalte an das von Ihnen gewählte Ziel weitergegeben.

Optionale GitHub-Verbindung

Wenn Sie GitHub verbinden, erhält der Synchronisierungsdienst von Scriba Ihre Kontokennung und die erforderliche Berechtigung für den Zugriff auf die freigegebenen Repositorys. Sitzung und Zugangsdaten werden auf dem Server verschlüsselt. In der iOS-App wird die nicht aussagekräftige Sitzungskennung im Schlüsselbund gespeichert; OAuth-Zugangsdaten werden nicht an den Editor zurückgegeben. Wenn Sie ein persönliches Zugriffstoken angeben, wird es an den Verbindungsdienst gesendet und nicht im Webspeicher aufbewahrt.

Bei der Synchronisierung werden Markdown-Dateien und Bilder über den Scriba-Dienst aus Ihrem GitHub-Repository gelesen oder in dieses geschrieben. Der Dienst bewahrt keine Dokumentbibliothek auf dem Server auf. GitHub speichert Dateien und den Commit-Verlauf entsprechend Ihren Berechtigungen und der Datenschutzerklärung von GitHub. In öffentliche Repositorys hochgeladene Dateien sind öffentlich.

Wenn Sie GitHub trennen, wird die Sitzung beim Dienst entfernt; Ihr Repository wird nicht gelöscht. Sie können Berechtigungen auch in Ihren GitHub-Kontoeinstellungen widerrufen. Inaktive Sitzungen laufen nach sieben Tagen ab. Das Löschen einer Notiz auf Ihrem Gerät entfernt keine früheren GitHub-Commits.

Infrastruktur

Die Website und der Synchronisierungsdienst verwenden HTTPS und Cloudflare. Diese Dienste verarbeiten technische Verbindungsdaten wie IP-Adresse, Zeitpunkt und angeforderten Pfad, um den Dienst bereitzustellen und zu schützen. Die Webversion kann technische Messwerte von Cloudflare nutzen. Das native iOS-Paket enthält kein SDK für Werbung, Tracking oder Nutzungsanalyse.

Scriba fordert keinen Zugriff auf Kontakte, Standort oder Mikrofon an und liest Ihre Fotomediathek nicht im Hintergrund. Bilder und Dateien wählen Sie selbst über die Systemauswahl aus; die Kamera wird nur verwendet, wenn Sie ein Foto zum Einfügen in eine Notiz aufnehmen möchten. Wir verkaufen Ihre Notizen nicht, verwenden Ihre Inhalte nicht für Werbung und senden Zeichnungen zum Rendern nicht an Server von Excalidraw oder Mermaid.

Kontrolle und Löschung

Exportieren Sie Ihre Notizen und Bilder, bevor Sie Websitedaten löschen oder die App entfernen. Diese Aktionen entfernen die privaten Kopien vom Gerät. Dateien, die Sie in „Dateien“, GitHub oder an einem anderen Ziel gespeichert haben, bleiben dort erhalten. Einstellungen, Zeichnungsentwürfe und private Symbolbibliotheken bleiben auf dem Gerät, bis die App-Daten gelöscht werden.
