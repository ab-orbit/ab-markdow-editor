# Nova nota pelo teclado — 1.15.0

**⌘⇧Enter / Ctrl+Shift+Enter** e o botão Nova nota compartilham o mesmo fluxo. Sem alterações, abrem uma nota em branco com foco no texto. Com edições ou sincronização pendente, oferecem Salvar e criar, Descartar e criar ou Cancelar. A criação só ocorre após uma gravação e sincronização bem-sucedidas. Cancelar a mensagem de commit, perder conexão ou encontrar conflito mantém a nota atual.

- [Chromium](new-note-chromium.txt) e [WebKit](new-note-webkit.txt): fonte, edição natural, texto ativo no whiteboard, cancelamento, descarte, salvamento privado, foco e proteção de configurações/modais.
- [Git real](new-note-git.txt): commit/push, falha de push, recuperação, mensagem de commit e arquivo externo alterado. Checkout e remoto temporários.
- Regressão dos atalhos anteriores: [navegador](shortcuts-browser.txt) e [local/Git](shortcuts-local.txt).
