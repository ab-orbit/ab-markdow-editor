# GitHub destination — one selection

Connect GitHub, filter the repository list if needed, then select one repository to activate autosave. The default note folder is `scriba`. There is no second repository selector or confirmation button. Advanced options contain folder customization, installation authorization, refresh and account disconnection. The connected state offers repository switching and disconnection.

Browser fixtures use synthetic repositories and never modify a customer's GitHub account. Chromium and WebKit journeys cover immediate selection, substring/case filtering, keyboard activation, service failure/retry, destination switching and viewport overflow at 1440×900 and 390×844.
