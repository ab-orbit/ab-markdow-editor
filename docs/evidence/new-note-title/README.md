# Título de nova nota

Nova nota começa em H1 vazio com foco. O título define o nome antes do primeiro salvamento; nomes ocupados recebem sufixos `(1)`, `(2)` etc. A lista do destino é consultada novamente ao salvar. Após o primeiro salvamento, o nome permanece estável ao editar o título. Caracteres incompatíveis com caminhos são substituídos.

Teste de navegador: `tests/new-note-title.spec.ts`, com repositório e remoto Git temporários, dois nomes ocupados e verificação do arquivo original preservado.
