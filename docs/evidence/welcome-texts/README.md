# Welcome notes — four languages

Synthetic, isolated browser libraries. The same Egyptian scribe image and eight bundled vector icons render in every locale. Resource examples are separate notes, selected by the same language preference.

- [Portuguese](pt-chrome.png)
- [English](en-chrome.png)
- [German](de-chrome.png)
- [French](fr-chrome.png)
- [Portuguese mobile — WebKit](pt-mobile-webkit.png)

The browser journey verifies source text, image loading, icon rendering, English fallback for an unsupported device language, changing the language in Settings, private edits, unpinning and deletion without reseeding. Local HTTP tests also cover filename/image collisions without overwriting user files.
